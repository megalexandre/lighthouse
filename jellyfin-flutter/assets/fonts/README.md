# Fonts

Noto Sans (Regular 400, SemiBold 600, Bold 700) and Noto Sans Mono (Medium
500), the faces the Lanterna design system names (assets/themes/lanterna.json).
Bundled so the app looks the same on every system and never fetches fonts.

Source: https://github.com/notofonts/notofonts.github.io, commit
412a7edb2c8c535d1066157e5b17e661fd5591fe, `fonts/<family>/hinted/ttf/`.

Inter (Regular 400, SemiBold 600, Bold 700, ExtraBold 800), the face of the
Prime theme (assets/themes/prime.json).

Source: https://github.com/rsms/inter, release v4.1, Inter-4.1.zip
(sha256 9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e),
