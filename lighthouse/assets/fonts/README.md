# Fonts

Noto Sans (Regular 400, SemiBold 600, Bold 700) and Noto Sans Mono (Medium
500), the faces the Lanterna design system names (assets/themes/lanterna.json).
Noto Sans Italic and Bold Italic too: Noto Sans is also the book reader's
default face (the free one closest to Amazon Ember), and books have italics.
Bundled so the app looks the same on every system and never fetches fonts.

Source: https://github.com/notofonts/notofonts.github.io, commit
412a7edb2c8c535d1066157e5b17e661fd5591fe, `fonts/<family>/hinted/ttf/`.
License: SIL Open Font License 1.1 (OFL.txt).

Inter (Regular 400, SemiBold 600, Bold 700, ExtraBold 800), the face of the
Prime theme (assets/themes/prime.json).

Source: https://github.com/rsms/inter, release v4.1, Inter-4.1.zip
(sha256 9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e),
`extras/ttf/`. License: SIL Open Font License 1.1 (Inter-OFL.txt).

The book reader's other faces (reader Display options), each Regular, Italic,
Bold and Bold Italic:

- Literata, a serif made for reading on screens. Source:
  https://github.com/googlefonts/literata, release 3.103, 3.103.zip
  (sha256 f7fb973cafb26cf785cbebaeaf51c18f87c15a3bcf4d82a7d4857564db5b056d),
  `fonts/ttf/`. License: SIL Open Font License 1.1 (Literata-OFL.txt).
- Atkinson Hyperlegible, made for low vision. Source:
  https://github.com/googlefonts/atkinson-hyperlegible, commit
  1cb311624b2ddf88e9e37873999d165a8cd28b46, `fonts/ttf/`. License: SIL Open
  Font License 1.1 (AtkinsonHyperlegible-OFL.txt).
